Moin

Da ihr ja teilweise ja auch noch Tuts für euer Magazin sucht hätte ich ein paar Themenvorschläge, die vileicht auch andere interessieren könnten. (aus aktuellem anlass)

Debuggen eines Booters / Betriebsystems
1. Welche Tools gibt es um ein os zu testen ( bochs, VM-Ware, .... )
2. Wie richte ich so ein Tool ein, Wie bedien ich es, z.B. Bochs. ( gibt ja noch leute die sowas gar nicht kennen ) ggf am beispiel eines schon hier vorgestellten Booters.
3. Wie kann ich mein os mit hochsprachen unterstützung Debuggen? Kann man den GDB mit einer PC-Simulation verbinden? (Hab hier vor kutzem was gelesen, das jemand mal sowas gemacht hat) Was ist ein Monitor, und wie binde ich ihn ein? ( der GDB hat meines wissens nach die Möglichkeit remot über die Serielle-Schnitstelle ein System zu debuggen. Dazu muss in der Software/OS ein Monitor eingebunden werden der auf der Seriellen - Schnittstelle mit dem GDB komuniziert.
4. Ist DOS als wirts System eine hilfe für die Entwicklung eines RM-OS? Welche DOS - Tools kann man verwenden, Debugger, ... Welche einschränkungen gibt es? Welche speicherbereiche sollte man nicht verändern, wellche IRQ sollte man tunlichst nicht verbigen, wass passiert wenn man es doch macht? ...

Viele werden die hier angesprochenen Themen schon kennen. für andere können diese aber durchaus neu sein.

gruss
