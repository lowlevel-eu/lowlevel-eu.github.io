Also im RM geht das recht einfach über das Interrupt 1Ah. Die Funktion 02h (Übergabe in ah) gibt dir die Uhrzeit zurück (ch = Stunde, cl = Minute, dh = Sekunde). Die Rückgabewerte sind BCD-Zahlen.

theorie:

es gibt aufm motherboard einen sogenannten CMOS-Speicher, der (soweit ich mit das richtig gemerkt hab) ~46 Bytes speichert. Dazu gehört das Datum, die Uhrzeit und eine Art "Flagteil", der speichert, wie das System zuletzt heruntergefahren wurde. das ding is an ne batterie angeschlossen, damit die Uhr und das Datum weiterlaufn. und das teil musste auslesen.
