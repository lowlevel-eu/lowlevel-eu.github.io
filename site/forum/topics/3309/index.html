Re: Android Emulierung
Zusätzlich zur (nahezu) kompletten Java-Umgebung brauchst du die Android-spezifischen APIs. Beides ist ziemlich komplett Java und damit theoretisch plattformunabhängig - allerdings müsstest du den Android-Teil für dein Windows Phone umsetzen. Da ich Windows Phone nicht kenne, weiß ich auch nicht, inwieweit sich die Bedienungskonzepte da unterscheiden. Dazu kommt dann noch eine Dalvik-kompatible Runtime, weil Android-Bytecode sich von gewöhnlichem Java-Bytecode unterscheidet. Wenn Anwendungen "native code" (d.h. C-Funktionen) verwenden, musst du außerdem noch eine POSIX-(Linux-)kompatible Umgebung bereitstellen; alle relevanten Anwendungen stellen aber generische Fallbacks bereit.

Ich weiß aber, warum ich mich von Windows Phone fernhalte. Wobei die meisten Apps bald(TM) auch für Windows portiert werden dürften - falls es sich durchsetzt.

Paula
