"FTP"-Synchronisierung
Hallo Leute,
einige werden sich jetzt fragen, warum ich das FTP in "" gesetzt habe. Nun, das hat den Grund, dass es nicht um die klassische Synchronisierung auf dem Server geht, wo ein Programm die Daten auf der HD mit den Daten auf dem Server vergleicht und bei Bedarf fehlende Daten runter- bzw. hochlädt.
Meine Frage ist, ob es ein Tool gibt, welches mir Daten, die ich auf meiner HD habe, die sich aber nicht mehr auf dem Server befinden, von meiner HD löscht? Um konkret zu werden, mein Vater sucht so ein Tool. Dies hat den Grund dass er sich die Updates von Linux immer mit einem FTP-Tool runterlädt, damit er wirklich ALLE Updates hat. Ob das nun nützlich ist oder nich, bitte ich nicht Thema der Diskussion werden zu lassen. Nun ist ihm heute aufgefallen, dass er einige Dateien auf seiner HD hat, die so garnich mehr auf dem Server vorhanden sind, aber es ist etwas mühevoll, jedes Verzeichnis und jede Datei zu überprüfen. Deswegen frage ich nach einem Tool, welches diese Aufgaben selbstständig übernimmt.
Hoffe mein Problem halbwegs verständlich gemacht zu haben ^^

Danke im Vorraus
