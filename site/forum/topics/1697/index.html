Schau dir mal mein Linkerscript an. Die Variablen __kernel_start__ und __kernel_end__ kann man im C/C++/Assembler code dann verwenden, zB:
Code: [Auswählen]
extern unsigned int __kernel_start__;
Die Adresse des Kernelanfangs ist dann &__kernel_start__.
