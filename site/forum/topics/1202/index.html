c kernel / richtige parameterübergabe?
Achso, wenn du die Parameter haben willst, machst du das am besten so:
Code: [Auswählen]
push bp
mov bp, sp

mov ax, [bp + 4]

pop bp
ret
oder
Code: [Auswählen]
enter 0, 0
mov ax, [bp + 4]
leave
ret

Das ist schneller und ändert BP nicht.
