Code: [Auswählen]

%include "strings.asm"

org 0x7C00 ; Unsere Startadresse

; -----------------------------------------
; Unser Bootloader
; -----------------------------------------



versuch es mal so:


Code: [Auswählen]
org 0x7C00 ; Unsere Startadresse

                    jmp   AfterInclude

%include "strings.asm"

AfterInclude:

; -----------------------------------------
; Unser Bootloader
; -----------------------------------------



Oder include ganz am Ende.
