Umfrage: Die schlechtesten OS
Jeder kennt es das eine OS das einem aus welchen Gründen auch immer nicht zusagt.
Bei mir war es Windows Phone 7. Oberflächlich gab es nichts zu meckern sehr hohe geschwindigkeit im alltag.
Aber im Vergleich zum Vorgänger OS Windows Mobile 6.5 hatte es was die Möglichkeiten viel einzustecken.
Am meisten hat mich aber entäuscht das HARET nicht mehr nutzbar war ebenso wie alle Anwendungen von WM.
HARET hat es möglich gemacht einen Kernel (zb Linux) aus WM heraus zu starten, auf manchen geräten sogar einen anderen Bootloader einrichten uvm.. (wenns interessiert -> https://github.com/haret/haret beispiel für einen haret basierten bootloader für qualcom msm https://gitorious.org/tinboot-for-linux-msm/tinboot-linux-msm/source/83b62957c5f376042c9a0697534d4e8a0adc09d2: )
Das viel bei WP7 alles weg was mein Hauptkritikpunkt ist.
Bin schon gespannt welche OS noch genannt werden.
