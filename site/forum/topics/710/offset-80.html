Booten von CD-ROM
Hi!

Ja, das kann ich schon, nur:
Booten von CD-ROM ist 1 zu 1 das gleiche wie von Diskette, da ISO-9660 (das standart-CD-Rom Format) es möglich macht, dass BIOS die CD-ROM wie eine Diskette behandelt (emuliert).

Um ein OS auf eine CD-Rom zu bekommen:

OS compiliern (.IMG) -> Nero Starten -> "Neue Zusammenstellung" -> "CD-ROM (Boot)" -> Startopt. -> "Image Datei" eingeben (alle Standart einstellungen beibehalten, da diese richtig sind) -> "Neu" -> "Ãffnet das Dialogfeld 'CD Brennen'" -> Brennen

Und damit hab ihr es.
