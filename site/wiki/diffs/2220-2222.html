== Programmieren des KBC ==
 
== Programmieren des KBC ==
 +
 +
Programmiert wird der KBC über die 2 Ports 0x60 und 0x64. Dabei werden auf den Ports nur Bytes gesendet und empfangen.<br>
 +
<br>
 +
Über das Port 0x64 kann man das Statusregister auslesen und KBC-Befehle senden.<br>
 +
<br>
 +
Das Port 0x60 dient als Ein-/Ausgabe Puffer. Parameter oder Rückgabewerte für einen Befehl werden über dieses Port geschrieben bzw. gelesen. Wenn keine Befehlsparameter erwartet werden und man auf das Port 0x60 schreibt, wird direkt an PSAUX0 weitergeleitet.<br>
 +
 +
*Vor dem Schreiben auf Port 0x60 oder 0x64 muss der Eingabepuffers leer sein. (Port[0x64].Bit[1] == 0)
 +
*Vor dem Lesen von Port 0x60 muss der Ausgabepuffers voll sein (Port[0x64].Bit[0] == 1)
 +
