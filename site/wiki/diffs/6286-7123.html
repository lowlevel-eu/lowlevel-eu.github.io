Die '''I/O APIC''' (= '''I/O Advanced Programmable Interrupt Controller''') löst den [[PIC | Programmable Interrupt Controller]] in einem [[SMP]]- bzw. [[NUMA]]-System ab. Da der PIC die [[IRQ | IRQs]] ausschließlich an den BSP (= Bootstrap Processor) senden kann, ist in einem System mit mehreren Prozessoren eine I/O APIC notwendig. Darüber hinaus stellt die I/O APIC statt nur 16 IRQ-Leitungen wie der PIC normalerweise 24 IRQ-Leitungen zur Verfügung. Dies verringert die Anzahl der von mehreren Geräten gleichzeitig genutzten IRQs in Systemen mit sehr vielen Geräten. Außerdem ist die Programmierung der I/O APIC schneller, da sie nicht über I/O Ports, sondern über Speicherbereiche abläuft.

== Programmierung ==
 
== Programmierung ==
−
Die I/O APIC besitzt ein Indexregister (''I/O Register Select'' bzw. ''IOREGSEL'') und ein Datenregister (''I/O Window'' bzw. ''IOWIN''). Beide sind les- und schreibbar. Das Indexregister befindet sich an Offset 0x00 und das Datenregister an Offset 0x10 im Speicherbereich des I/O APIC, der bei einem PIIX3 Chipsatz bei 0xfec00xy00 (x und y werden mit dem APICBASE Register im PIIX3 festgelegt) beginnt. Im Allgemeinen ist die Basisadresse der I/O APICs über die [[Symmetrisches_Multiprozessorsystem#Intel_Multiprocessor_Specification | Multiprocessor Tabellen]] bzw. die [[ACPI | ACPI-Tabellen]] auslesbar. Mit dem Indexregister wählt man ein internes Register der I/O APIC aus und kann dann über das Datenregister das interne Register auslesen bzw. beschreiben.
+
 
 +
=== Basisadresse der I/O APIC ===
 +
 
 +
Die Basisadresse dieser Speicherbereiche kann im Allgemeinen über die [[Symmetrisches_Multiprozessorsystem#Intel_Multiprocessor_Specification | SMP]]- bzw. die [[ACPI | ACPI]]-Tabellen ausgelesen werden. Bei einem PIIX3 Chipsatz beginnt der Speicherbereich bei 0xFEC00xy00 (x und y werden mit dem APICBASE Register im PIIX3 festgelegt).
 +
 
 +
=== Lesen/Schreiben der internen Register ===
 +
Die I/O APIC besitzt ein Indexregister (''I/O Register Select'' bzw. ''IOREGSEL'') und ein Datenregister (''I/O Window'' bzw. ''IOWIN''). Mit dem Indexregister wählt man ein [[I/O APIC#Interne Register | internes Register]] der I/O APIC aus und kann anschließend über das Datenregister das interne Register auslesen bzw. beschreiben.
 +
 
 +
Folgender Code kann dazu verwendet werden auf die internen Register zuzugreifen:
 +
<c>
 +
/* Offset der memory-mapped Register */
 +
#define IO_APIC_MMREG_IOREGSEL 0x00
 +
#define IO_APIC_MMREG_IOWIN    0x04
 +
 
 +
/* Basisadresse, sollte vorher initialisiert werden */
 +
uint8_t * volatile io_apic_base;
 +
 
 +
/* Lesen eines internen Registers */
 +
uint32_t io_apic_read(uint8_t index)
 +
{
 +
  *(io_apic_base + IO_APIC_MMREG_IOREGSEL) = index;
 +
  return *(uint32_t * volatile)(io_apic_base + IO_APIC_MMREG_IOWIN);
 +
}
 +
 
 +
/* Schreiben eines internen Registers */
 +
void io_apic_write(uint8_t index, uint32_t value)
 +
{
 +
  *(io_apic_base + IO_APIC_MMREG_IOREGSEL) = index;
 +
  *(uint32_t * volatile)(io_apic_base + IO_APIC_MMREG_IOWIN) = value;
 +
}
 +
</c>
 +
 
 +
=== Setzen der Einträge der ''Redirection Table'' ===
 +
Die Einträge der ''Redirection Table'' werden basierend auf den Informationen, die die [[Symmetrisches_Multiprozessorsystem#Intel_Multiprocessor_Specification | SMP]]- bzw. die [[ACPI | ACPI]]-Tabellen enthalten, gesetzt.
