==== MinGW ====
−
MinGW ist ein auf MS Windows portierter gcc. Für mehr Informationen siehe [[Crosscompiler_für_Windows|Cross-Compiler für Windows]]
+
MinGW ist ein auf MS Windows portierter GCC. Die neueste Version des Installers für MinGW kann man auf der Projektseite unter [http://sourceforge.net/projects/mingw/files/Automated%20MinGW%20Installer/mingw-get-inst/ Automated MinGW Installer / mingw-get-inst] herunterladen. Bei der Installation sollte man das MSYS Base System noch auswählen. Um GCC zu kompilieren muss man außerdem GMP, MPFR und MPC nachinstallieren, indem man nach der Installieren mingw-get in der MinGW Shell aufruft:
−
 
+
mingw-get install gmp mpfr mpc
