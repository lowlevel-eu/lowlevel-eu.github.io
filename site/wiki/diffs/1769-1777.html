Es gibt mehrere KBC-Typen. Grob kann man alle diese Typen jedoch in zwei Arten einteilen.
−
 
+
=== XT-KBC ===
−
 
+
In alten XT-Systemen wurde nur über das Programmable Peripheral Interface (PPI) mit der Tastatur kommuniziert. Alle Scancodes der gedrückten Tasten konnten über Port 0x60 gelesen werden. Über die Bits 6-7 von Port 0x61 wird die Tastatur ein und aus geschaltete.<br>

 +

=== CPU-reset ===
 +
Der CPU-Reset wird ausgelöst indem der Wert 0xFE in das Outputport geschrieben wird.
 +
<pre>
 +
;Warten bis der Eingabepuffer lehr ist
 +
wait:
 +
in  al, x064
 +
test al, 00000010b
 +
jne  wait
 +
 +
;Befehl 0xD1 zum schreiben des Inputports an den KBC senden
 +
mov  al, 0xD1
 +
out  0x64, al
 +
 +
;Wieder warten bis der Eingabepuffer lehr ist
 +
wait2:
 +
in  al, x064
 +
test al, 00000010b
 +
jne  wait2
 +
 +
;Den neuen Wert für das Inputport über Port 0x60 senden
 +
mov  al, 0xFE
 +
out  0x60, al
