Programme können in beliebig viele Tasks unterteilt werden. Somit bekommen aufwendige Programme automatisch mehr Rechenzeit und eine Aufteilung in Threads für mehrere Prozessoren wird so ganz einfach. Damit ist auch die Möglichkeit geschaffen für Software verschiedene Module für einen Zweck anzubieten. Bestimmte Module könnten dann von mehreren Programmen genutzt werden, was im Idealfall zur Verflechtung aller laufenden Programme führt.  
 
TriviaOS wird also mit mehreren Prozessoren umgehen können, aber eine 64-Bit Version ist vorläufig nicht geplant, da ich es wichtiger finde, dass die gesamte Rechenpower genutzt wird, anstatt von etwas mehr Speicher, welchen ich momentan sowieso nicht brauche...
