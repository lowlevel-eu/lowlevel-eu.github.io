==Aktueller Windows-Build==
 +
Die letzten zumindest halboffiziellen Builds für Windows stammen aus 0.9.x-Zeiten. Aus diesem Grund werden unter Windows oft deutlich veraltete qemu-Versionen verwendet, deren Fehler gerade bei der Betriebssystementwicklung gelegentlich auffallen. Eine einigermaßen aktuelle Version für Windows (git-Version von Ende Juni 2009) liegt auf unserem Server: [http://lowlevel.brainsware.org/download/qemu-0.10.50-i386.tar.bz2]
