==== Kernel ====
−
Über das Design von Windows ist relativ wenig bekannt, da von Microsoft relativ wenig Informationen über Schnittstellen etc. offenlegt. Deshalb ist man sich auch nicht wirklich einig, was den [[Kernel]] von Windows betrifft. Ursprünglich war Windows als [[Mikrokernel]] geplant, bis Windows NT 3.1 war das auch so. Allerdings wurden dann aus Geschwindigkeitsgründen Teile der [[GUI]] als Ring-0 Applikationen ausgeführt, genauso wie andere Teile. (mittlerweile - in Vista - werden die Grafiktreiber wieder als Ring-3 Prozesse angesehen) Deshalb entspricht Windows nicht mehr den Kriterien von [[Mikrokernel]]-Systemen. Daher wird Windows gemeinhin als [[Macrokernell]] betrachtet.
