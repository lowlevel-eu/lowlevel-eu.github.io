== VBE im Protected Mode ==
 
== VBE im Protected Mode ==
−
Vorweg: Es ist nicht möglich, mit VBE einen Grafiktreiber komplett im [[Protected Mode]] zu entwickeln. Wenigstens das Umschalten in den gewünschten Grafikmodus muss im Real Mode erfolgen!
+
Vorweg: Es ist nicht möglich, mit VBE einen Grafiktreiber komplett im [[Protected Mode]] zu entwickeln. Wenigstens das Umschalten in den gewünschten Grafikmodus muss im Real Mode erfolgen! Allerdings ist man auf die VBE Funktionen im PM auch nicht mehr angewiesen, wenn man sich für das [[LFB]] Modell entschieden hat und nachträglich nicht mehr die Auflösung wechseln möchte.
 +
 
 +
Mit VBE 2.0 wurde das sogenannte "Protected Mode Interface" eingeführt. Das sind Funktionen, die die Grafikkarte zur Verfügung stellt und die im Gegensatz zu den anderen Funktionen in 32Bit Protected Mode Code vorliegen. Die Adresse dieser Funktionen erhält man mit folgendem Auftuf, der allerdings immer noch im Real Mode stattfinden muss:
 +
*AX = 4F0Ah
 +
*BL = 00h
 +
Diese Funktion liefert folgende Werte zurück:
 +
*ES:DI=Zeiger auf eine Tabelle des unten stehenden Formats
 +
*CX=Länge der Tabelle

== Pixel zeichnen ==
 +
=== Im Protected Mode ===
 +
Um im Protected Mode Pixel zu zeichnen, muss man in den Grafikspeicher schreiben. Hier zeigt sich auch der Vorteil des LFB: er ist im PM viel einfacher und schneller zu handhaben!
 +
Wenn man also mithilfe des LFB Zugriff auf den Grafikspeicher hat, dann zeichnet man ein Pixel folgendermaßen:
 +
<c>
 +
unsigned int* lfb = (unsigned int*) vbe_mode_info.phys_base_ptr;
 +
void draw_pixel(unsigned int x, unsigned int y, unsigned int color)
 +
{
 +
  lfb[x + y*vbe_mode_info.bytes_per_scan_line = color;
 +
}
 +
</c>
 +
 
 +
Wenn man allerdings das paged Modell verwendet, muss man erst den entsprechenden Teil des Grafikspeichers in den Adressraum blenden mithilfe des "Bank Switch".
 +
 
 +
=== im Real Mode ===
 +
Im Real Mode kann man die obige Variante theoretisch auch verwenden, wenn der Grafikspeicher sich nicht oberhalb der 1MB Marke im Adressraum befindet.
