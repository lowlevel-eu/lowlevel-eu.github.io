<b>BCD</b>(<b>B</b>inary <b>C</b>oded <b>D</b>ecimal)ist ein Format zur binären Kodierung von Dezimalzahlen. Man unterscheidet zwischen gepackten- und ungepackten-BSD Zahlen.
 +
 
 +
Im '''BCD''' Format werden die einzelnen Dezimalstellen einer Zahl in jeweils einem Nibble(4Bit) gespeichert.
 +
Dies kann man mit der folgenden Tabelle machen:
  
 
{| border="1"
 
{| border="1"

| 9      || 1001
 
|}
 
|}
 +
 +
==gepackte BCD Zahlen==
 +
Im gepackten BCD-Format befinden sich die Nibble der BCD-Zahl direkt hinter einander.
 +
Beispiel:
 +
Dezimal  : 42
 +
Gepacktes BCD-Format: 0100 0010b (0x42)
 +
 +
==ungepackte BCD Zahlen==
 +
Im ungepackten BCD-Format steht jedem BCD-Nibbel ein leeres Nibbel voran.
 +
Beispiel:
 +
  Dezimal  : 42
 +
  Ungepacktes BCD-Format: 0000 0100b  0000 0010b (0x04 0X02)
 +
Der Vorteil hierbei ist, dass durch eine einfache '''or'''-Verknüpfung mit 0x30 eine BCD-Ziffer in das passende ASCII-Zeichen umgewandelt werden kann.
