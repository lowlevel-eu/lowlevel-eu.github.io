== Entwickeln einer GUI für das eigene OS ==
−
Die meisten OS-Developer wollen eine GUI für ihr OS haben. Doch besonders viele Anfänger wollen quasi sofort eine GUI mit allem Drum und Dran haben. Dabei sollte jedem klar sein, dass eine GUI ein hochkomplexes Programm ist, vergleichbar mit einem aufwändigen 3D-Spiel. Und wo es gerade erwähnt wurde: Eine GUI ist ein '''Programm''', soll also vom Kernel '''geladen und ausgeführt''' werden. Eine GUI ist '''kein''' Bestandteil des [[Kernel|Kernels]]! Auch die GUI von [[Windows]] gehört nicht zum Kernel, wie oft angenommen wird (allerdings sind GUI und Kernel über die WinAPI und verschiedenste [[Syscall|Syscalls]] eng miteinander verzahnt).
