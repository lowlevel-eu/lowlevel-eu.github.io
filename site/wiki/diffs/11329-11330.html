Die Geräte besitzen zwei I/O-Räume, der erste heißt NAM-BAR (Native Audio Mixer BAR) und der zweite NABM-BAR (Native Audio Bus Master BAR). VIAs AC'97-Soundkarte ist Funktion 5 der Southbridge, die sich ihre IO-Adressräume mit dem integrierten Modem (MC97) in Funktion 6 teilt. Wir behandeln im Folgenden nur AC'97. Der für uns relevante IO-Raum für DMA residiert im ersten PCI-BAR.
 +
 +
Die Karte bezieht Sounddaten aus aus mehreren Puffern, die in der SGD-Tabelle ("Scatter/Gather DMA Table") durch Deskriptoren folgenden Formats beschrieben werden. Die Basisadresse der Tabelle ist in das 32-bit-Register an Offset 0x4 zu schreiben und an 2-Byte-Grenzen auszurichten:
 +
<c>typedef struct
 +
{
 +
uint32_t buf;
 +
uint32_t len      : 24;
 +
uint32_t reserved :  5;
 +
uint32_t stop    :  1; // Transfer am Ende des Blocks unterbrechen. Um fortzufahren, setze Bit 2 in Register 0 (Audio SGD Read Channel Status)
 +
uint32_t flag    :  1; // Transfer am Ende des Blocks unterbrechen. Löst einen FLAG-Interrupt aus.
 +
uint32_t eol      :  1; // Letzter Eintrag. Löst einen EOL-Interrupt aus.
 +
} __attribute__((packed)) ac97Via_SGDEntry_t;</c>
