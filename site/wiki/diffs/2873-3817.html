VirtualBox ist ein x86 Emulator der Firma innotek. Es gibt zwei Versionen der Software, wobei eine unter Open Source Lizenz steht.<br>
 
Die Software kann unter [[Windows]], und Unix ([[Linux]], Mac OS X, etc...) eingesetzt werden.<br>

VirtualBox verfügt über eine [[GUI|grafische Benutzeroberfläche]]. Was die Software im Gegensatz zu anderen Emulatoren sehr viel benutzerfreudlicher macht.

Besondere Features:
 +
* iSCSI für Blockgeräte
 +
* Fernsteuerung der VM via RDP, inklusive Support für USB über RDP
 +
* Gastunsterstützung um unter offiziell unterstützen Betriebssystemen Geschwindigkeitsvorteile und weitere Features anbieten zu können.
 +
 +
Virtualisierte Hardware:
 +
* Siehe [[Qemu|QEMU]] (VirtualBox stammte anfangs von QEMU ab)
 +
* ACPI, inklusive ACPI Power Status (mit Anbindung an Host)
 +
* I/O APIC
