== Cluster ==
−
Ein Cluster ist die kleinste adressierbare Einheit, auf jeder Dieskette und Festplatte.
+
Ein Cluster ist die kleinste von FAT verwaltete Einheit, auf jeder Diskette und Festplatte, und besteht aus einem oder mehreren (für gewöhnlich eine Zweierpotenz) Datenträger-Sektoren.
−
Bei Diesketten, die mit FAT12 formatiert sind, ist ein Cluster immer 512 Byte groß. Somit nimmt auf der Diskette jede datei mindestens 512 Byte in anspruch, auch wenn si nur 32 Byte groß ist. Eine 2312 Byte große Datei würde jezt 5 Cluster Belegen und fast ein halber Cluster bleibt frei.
+
Bei Disketten, die mit FAT&nbsp;12 formatiert sind, ist ein Cluster immer 1 Sektor (also für gewöhnlich 512 Byte) groß. Somit nimmt auf der Diskette jede Datei mindestens 512 Byte in Anspruch, auch wenn sie tatsächlich nur 1 Byte groß ist. Eine 2312 Byte große Datei würde dort 5 Cluster Belegen und fast ein halber Cluster bleibt frei.
−
Größeren Massenspeicher wie Festplatten sind natürlich nicht mit FAT 12 formatiert. sondern meißtens mit FAT32 oder NTFS. UM NTFS kümmern wir uns in diesem Artikel aber nicht. Bei FAT 32 kann man 2^28 Cluster adressieren. Meistens sind bei FAT32 4096 Bytes zu einem Cluster zusammengefasst Somit nimmt jede noch so kleine Datei 4096 Byte in anspruch nehmen.
+
Größere Massenspeicher wie heutige Festplatten sind natürlich nicht mit FAT&nbsp;12 formatiert, sondern meißtens mit FAT&nbsp;32 oder NTFS. Um NTFS kümmern wir uns in diesem Artikel aber nicht. Bei FAT&nbsp;32 kann man 2^28 Cluster adressieren. Meistens sind bei FAT&nbsp;32 8 Sektoren (also für gewöhnlich 4096 Bytes) zu einem Cluster zusammengefasst, somit nimmt dort jede noch so kleine Datei mindestens 4096 Byte in Anspruch.
