Hardware Abstraction Layer

Die HAL (Hardware Abstraction Layer) bezeichnet eine Softwareschicht, die zwischen der Hardware und dem Betriebssystemkernel liegt. Sie hat die Aufgabe, hardwarespezifische Funktionen auszulagern, um eine spätere Portierung zu erleichtern, da im besten Fall nur die HAL angepasst werden muss. Auch Microsoft Windows hat eine eigene HAL, die als Datei hal.dll vorliegt.

Aufgaben

Die HAL beinhaltet somit folgende Aufgaben:

  • I/O Port-Zugriffe
  • Interrupts
  • GDT, IDT, ...
  • Syscalls
  • ...

Exokernel

Eine besondere Rolle hat der Exokernel. Dieser hat normalerweiße kein HAL.
