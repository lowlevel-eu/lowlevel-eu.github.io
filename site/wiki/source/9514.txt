StefanOS hat die Aufgabe einen PC schnell und einfach zu benutzen.
Das OS wird dafür (voraussichtlich) einen Dateisystemtreiber für [[FAT]] im Kernel haben.
Die Shell wird als .elf oder .bin Datei von GRUB geladen.

== Programme ==
Für Programme kann man [http://sfan.funpic.de/StefanOS_source/libstefanos.h|LibStefanOS] benutzen.
<c>
#include "libstefanos.h"

int main() {
  putc('H');
  print("ello World!");
  kill_process(get_pid());
}
</c>
Das <i>kill_process(get_pid());</i> ist dabei zwingend notwendig um die Anwendung zu beenden.
