== Beschreibung ==
Haiku ist ein Betriebssystem, welches eine Reimplementierung von [https://de.wikipedia.org/wiki/BeOS BeOS] darstellt, allerdings nicht auf dessen Quellcode aufbaut. Es wird seit dem 18. August 2001 entwickelt und war vorher als ''OpenBeOS'' bekannt.


== Features ==
* SMP
* GUI
* AHCI 
* BFS (Be File System)
* x86-64 
* Radeon Grafikarten-Treiber (diese können einen eigenen Grafikmodus aufsetzen und unterstützen sogar teilweise Multimonitor-Setups und 2D-Beschleunigung)
