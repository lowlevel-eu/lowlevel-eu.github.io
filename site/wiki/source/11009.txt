= Vivian =
Da mein Betriebssystem eine Sicherheit von 100% haben soll, habe ich einiges zum Thema Bootloader, BIOS/UEFI und Firmware gelesen. Heraus kam aber nichts gutes: Wenn ich mein Ziel verwirklichen will, muss ich mindestenst den BIOS/UEFI-Code ändern oder noch besser - die Gesamte Firmware aller Chips ändern.
Pro- und Kontrapunkte beim Codeändern:
:+ Ich habe den Code vor meinen Augen und weiß, was wann passieren wird
:+ Sicherheitslecks, welche im Code stehen können, werden geschlossen 
:+ Ich kann Systemnah programmieren wodurch Vivian schneller wird
:+ Ich kann die Hardware kontrollieren, welche Unterstützt wird
:- Es gibt keine Dokumentation von Intel AMD usw., da sonst die Konkurenz abkupfern kann
:- Hintertürchen, welche in der Hardware eingebaut wurden, können nicht geschlossen werden
:- Ich muss meinen BIOS-Code veröffentlichen, da sonst mein Code als "Gefährlich" gelten könnte
:- Ich muss für jeden Chip eine eigene Firmware schreiben und die Liste ist lang
Mir ist klar, wie viel Arbeit das ist, aber ich möchte ein sicheres OS auf die Beine stellen. Aber solange ich keinen Test-PC habe, kann ich nur planen :)
