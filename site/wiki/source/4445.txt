Bei Logical Block Addressing (Logische Block Adressierung) werden Sektoren von Massenspeichern von 0 aufsteigend adressiert. Das Gegenstück zu LBA ist das ältere [[Cylinder Head Sector|CHS]].

Umrechnung von LBA zu [[CHS]]:

    Abkürung Bedeutung
    
    mS       maximale Anzahl Sektoren (auf einem Zylinder)
    mH       maximale Anzahl Köpfe
    
    S        Sektor
    H        Kopf
    C        Zylinder

    C =   LBA  /  (mH*mS)
    H =  (LBA mod (mH*mS))  /  mS
    S = ((LBA mod (mH*mS)) mod mS) + 1
