Die '''Machine-Specific Register'''s bzw. '''Model-Specific Register'''s ('''MSR''') sind Prozessorregister. Sie können im Gegensatz zu anderen Registern nur mit den Instruktionen ''rdmsr'' und ''wrmsr'' ([[x86]] und [[x86-64]]) angesprochen werden. Außerdem sind diese Register spezifisch für eine bestimmte Prozessorfamilie/-generation, d.h. sie müssen von folgenden Prozessoren nicht bzw. nicht genauso implementiert werden.

== WRMSR/RDMSR ==
Mit folgendem Code kann man auf die MSRs zugreifen:
<c>uint64_t rdmsr(uint32_t msr)
{
   uint32_t lomsr, himsr;
   uint64_t content;

   __asm__ __volatile__ ("rdmsr":"=a"(lomsr),"=d"(himsr):"c"(msr));

   content = himsr;
   content <<= 32;
   content |= lomsr;
   return content;
}

void wrmsr(uint32_t msr, uint64_t value)
{
   uint32_t lomsr, himsr;

   lomsr = value & 0xFFFFFFFF;
   himsr = value >> 32;
   __asm__ __volatile__ ("wrmsr"::"a"(lomsr),"c"(msr),"d"(himsr));
}</c>
