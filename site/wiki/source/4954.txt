Der '''Programmable Interval Timer''' oder kurz '''PIT''' ist ein Signal erzeugender Baustein auf dem Mainboard. Er erzeugt ein Signal in einer Frequenz von 1193180 Hz. Er wird u.a. für den sleep()-Befehl gebraucht oder sonstige zeitbedingte Aufgaben.

Der '''Programmable Interval Timer''' (= '''PIT''') erzeugt ein Signal mit der Frequenz von 1193180Hz.

== Funktionsweise ==
Das Signal von dem die Rede ist, zählt drei Register herunter, welche jeweils eine Aktion auslösen sobald sie 0 erreichen:

* Zählregister 1: Das Auslösen des [[IRQ]] 0 (dient Betriebssystemen zur Zeitmessung und wird oft für Multitasking genutzt)<br>
* Zählregister 2: Dient in alten XT-PCs, zusammen mit dem DMA-Kanal 0, der Speicherauffrischung<br>
* Zählregister 3: Signal für den [[Systemlautsprecher]] (also die Tonfrequenz)<br>

Die Frequenz für das Auslösen errechnet sich aus der Grundfrequenz und dem Wert im Register der heruntergezählt wird (Teiler).<br>

1193180 Hz / Teiler = Auslöse-Frequenz<br>

Der Teiler ist ein 16-Bit groß, kann also Werte von 0 bis 65535 aufnehmen. Der Wert 0 wird jedoch als 65536 interpretiert, weshalb sich ein möglicher Teilerwert von 1 bis 65536 ergibt.<br>

Der Minimal- und Maximalwert des Teilers bestimmt die möglichen Auslöse-Frequenzen:<br>

Max: 1193180 Hz /     1 = 1193180 Hz<br>
Min: 1193180 Hz / 65536 = ~18.206 Hz<br>

Ports: 40h bis 43h
