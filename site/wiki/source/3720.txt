Nuke ist mein Hobby OS, welches im Protected Mode läuft. Hauptziel von Nuke ist es, dem Benutzer eine schnelle Arbeit am Computer zu gewährleisten.
 
== Entwickler ==
* [[Benutzer:SHyx0rmZ | SHyx0rmZ]]
== Aktuelle Features ==
* Textausgabe
* Register Debugging
* 640x480x4 VGA

== Historie ==
Die Versionsnummer besteht aus 5 Hex-Ziffern. Sie kann im Bootsektor an Adresse 0x127 - 0x12B ausgelesen werden.
''Kursiver Text'' zeigt noch nicht implementierte Features an.


Ver 00002
* GDT wird geladen
* ''IDT''
* ''Exception Handling & IRQs'' //Schreitet voran
* Protected Mode
* ''FAT12''
* ''NukeFS''

Ver 00001
* Werte der Register auslesbar
* VGA
* Kernel wird von Floppy gelesen

Ver 00000
* Bootloader gibt ''Hallo Welt'' aus und rebootet nach Tastendruck
