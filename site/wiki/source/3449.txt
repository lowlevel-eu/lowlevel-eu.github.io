Nuke ist mein Hobby OS, welches zur Zeit noch im Real Mode läuft. Hauptziel von Nuke ist es, dem Benutzer eine schnelle Arbeit am Computer zu gewährleisten.
 
== Entwickler ==
* [[Benutzer:SHyx0rmZ | SHyx0rmZ]]
== Aktuelle Features ==
* Textausgabe
* Register Debugging
* 320x200x8 VGA

== Historie ==
Die Versionsnummer besteht aus 5 Hex-Ziffern. Sie kann im Bootsektor an Adresse 0x127 - 0x12B ausgelesen werden.

Ver 00001
* Werte der Register auslesbar
* VGA
* Kernel wird von Floppy gelesen

Ver 00000
* Bootloader gibt ''Hallo Welt'' aus und rebootet nach Tastendruck
