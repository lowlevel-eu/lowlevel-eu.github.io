LF OS ist ein weiteres Hobbybetriebssystem das in C und Assembler programmiert ist.

Folgende Features sind bereits implementiert:
* Basics (GDT, IDT, IRQ Handler ...)
* Tastaturtreiber
* VESA Grafikmodus (von GRUB initialisiert)
* eine einfachste Shell (nur im Textmodus)
* Physische Speicherverwaltung
* ELF-Loader
* Multitasking im Usermode
* eine einfachste API

Folgende Features sind momentan in Arbeit:
* Maustreiber (noch einige Bugs ...)
* Paging

Folgende Features fehlen noch:
* Dateizugriffe (Speichergeräte, Dateisysteme ...)
* Klickibunti-Oberfläche
* ein Treiberinterface (Planung bereits fertig)

Sollte es Fragen geben, können diese gerne im LF OS Forum gestellt werden.
Die englische Version unter [http://www.lf-os.tk http://www.lf-os.tk] <strike>spinnt manchmal etwas</strike> (sollte behoben sein ...), die deutsche unter [http://littlefox.web-fuxx.de http://littlefox.web-fuxx.de] funktioniert in der Regel.
