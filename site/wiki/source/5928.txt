Ein '''Editor''' ermöglicht das Bearbeiten von einfachen Textdateien. Im Gegensatz zu Textverarbeitungsprogrammen werden die Dokumente von einem Editor jedoch als reiner Text gespeichert, also völlig ohne z.B. Formatierungen (außer natürlich Tabs o.ä.).

Ein Texteditor kann zwar so simpel sein wie Microsofts Notepad, der bei [[Windows]] dabei ist, jedoch bevorzugen fast alle Programmierer einen Editor mit mehr Features. Außerdem unterstützt Notepad keine Unix-Zeilenumbrüche, daher ist ein verbesserter Editor für das gemeinschaftliche Arbeiten unter Windows obligatorisch.

Einige Texteditoren bieten nur wenige erweiterte Optionen, wie zum Beispiel Syntax-Highlighting, andere lassen sich durch verschiedenste Plugins und Einstellungsmöglichkeiten mit einer leichtgewichtigen IDE vergleichen. Dieser Artikel listet verschiedene Texteditoren auf.

== Linux ==
* [http://kate-editor.org/ Kate] ist ein komfortabler Editor, der bei KDE mitgeliefert wird.

* [http://projects.gnome.org/gedit/ Gedit] wird bei GNOME mitgeliefert, hat jedoch weniger Features als Kate.

== Windows == 
* [http://notepad-plus.sourceforge.net/ Notepad++]

* [http://www.flos-freeware.ch/notepad2.html Notepad2]

* [http://www.contexteditor.org/ ConTEXT]

== Sowohl, als auch ==
* [http://gobby.0x539.de/ Gobby] basiert auf GTK. Die Besonderheit dieses Editors ist, dass er mehreren Entwicklern ermöglicht, gleichzeitig über Netzwerk und Internet an einem Dokument zu arbeiten.

* [http://www.geany.org/ Geany] ist ein Editor mit Eigenschaften einer IDE. Man kann Dateien in Projektform verwalten und Informationen zu Funktionen, Variablen einer Datei werden ebenfalls geordnet angezeigt

* [http://www.vim.org/ Vim], der Nachkomme des Unix-Editor-Großväterchens vi. Vim ist kommandozeilenbasiert, es gibt jedoch auch einen grafischen Client namens GVim.

* [http://www.gnu.org/software/emacs/ Emacs], eines der bekanntesten GNU-Programme. Komplett mit Lisp-Interpreter und einem Haufen Plugins.

* [http://www.scintilla.org/SciTE.html Scite] ist ein sehr mächtiger Editor mit Eigentschaften einer IDE. Das Bauen von Projekten lässt sich direkt aus Scite per Tastendrück durchführen

* [http://www.nano-editor.org Nano], freier Pico-Klon, kommandozeilenbasiert, mit Syntax-Highlighting
