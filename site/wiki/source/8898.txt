'''Sebo OS''' ist ein Hobby-OS.


== Eine kleine Beschreibung ==
Das OS wird in einer 7-Zip Datei sein, so dass, Linux und Windows User das öffnen können. Das OS ist opensource und frei zu bekommen. Um ihn zu starten, braucht man Bochs. Der Bootloader ist GRUB oder irgendein anderer.
