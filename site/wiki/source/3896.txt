== td-Tags ==

Was machen td-Tags hier für einen Sinn?
Die Vorlage wird so verwendet:
 &nbsp;{| { {Prettytable} }
 
 wird zu ...
 
 &nbsp;{| {{Prettytable}}
ohne die tags wäre es korrekt und z.B. das style-Attribut würde nicht ignoriert werden.
