Diese Seite fasst die wichtigsten Formatierungsbefehle, die man in diesem Wiki verwenden kann, zusammen. In erster Linie ist sie dafür gedacht eine schnelle Übersicht über die Gestaltungsmöglichkeiten zu liefern, und ist deswegen in einem relativ knappen Stil gehalten. Eine umfangreichere Dokumentation bietet die offizielle [http://www.mediawiki.org/wiki/Help:Contents/de MediaWiki-Dokumentation]. 

== Text ==
Um Text hervorzuheben, wird dieser von jeweils zwei oder drei Apostrophen (') vorne und hinten eingeschlossen.

Beispiel:
<nowiki>''kursiv'' und '''fett'''</nowiki> wird zu ''kursiv'' bzw. '''fett'''

== Überschriften ==
Überschriften werden von jeweils zwei oder mehr Gleichheitszeichen (=) vorne und hinten eingeschlossen. Die Überschriften der obersten Ebene, werden von zwei Gleichheitszeichen umschlossen, und niedrigere Ebenen von mehr als zweien.

<nowiki>== Erste Überschriftsebene ==</nowiki>

<nowiki>=== Zweite Überschriftsebene ===</nowiki>

Überschriften, die von nur einem Gleichheitszeichen umschlossen sind, existieren zwar auch, werden aber in den Artikeln '''nicht''' benutzt, da diese eine Überschrift erster Ordnung darstellen und damit semantisch auf der selben Ebene wie die Artikelüberschrift ständen.

Vor einer Überschrift wird genau eine Zeile freigelassen.

=== Inhaltsverzeichnis ===
Wenn eine bestimmte Anzahl an Überschriften im Artikel vorhanden ist, generiert die MediaWiki-Software automatisch ein Inhaltsverzeichnis. Dieses wird vor der ersten Überschrift (also nach den einleitenden Absätzen) platziert. 

== Links ==
* <nowiki>[[Artikelname]]</nowiki> - Bsp: <nowiki>„Ein [[Interrupt]]“</nowiki> wird zu: „Ein [[Interrupt]]“
* <nowiki>[[Artikelname|Text im Artikel]]</nowiki> - Bsp: <nowiki>„Eine [[Interrupt|Unterbrechung]] macht Spaß“</nowiki> wird zu: „Eine [[Interrupt|Unterbrechung]] macht Spaß“
* <nowiki>[http://example.com externer Link]</nowiki> - Bsp: <nowiki>„Das [http://www.lowlevel.eu Lowlevel-Wiki] macht Spaß“</nowiki> wird zu: „Das [http://www.lowlevel.eu Lowlevel-Wiki] macht Spaß“
* <nowiki>[http://example.com]</nowiki> - Bsp: „Siehe <nowiki>[http://www.lowlevel.eu]</nowiki>“ wird zu: „Siehe [http://www.lowlevel.eu]“

== Listen ==
=== Nicht nummeriert ===
 * punkt x
 * punkt y
 * punkt z
wird zu:
* punkt x
* punkt y
* punkt z
=== Nummeriert ===
 # punkt x
 # punkt y
 # punkt z
wird zu:
# punkt x
# punkt y
# punkt z
=== Mehrere Ebenen (kombiniert)===
 * foo
 *# unterfoo1
 *#* unterunterfoo
 *# unterfoo2
 * bar
wird zu:
* foo
*# unterfoo1
*#* unterunterfoo
*# unterfoo2
* bar

== Tabellen ==
Tabellen werden immer durch ein „{|“ begonnen und mit „|}“ beendet. Dazwischen definiert man dann die einzelnen Reihen. Die Inhalte einer Reihe werden wiederrum durch „|-“ voneinander abgegrenzt. Jede Zelle selbst wird auf im Code auf eine eigene Zeile geschrieben, die mit „|“ beginnen muss, um anzuzeigen, dass nun eine neue Zelle der aktuellen Reihe beginnt. Außerdem kann man eine Überschriftenzelle erzeugen, die aber statt mit „|“ mit „!“ beginnen muss.

Es empfiehlt sich in der ersten Zeile der Tabelle (nach dem „{|“) diese mit dem Attribut <nowiki>{{prettytable}}</nowiki> zu versehen, um den [[Designrichtlinien]] treu zu bleiben. Außerdem sieht es einfach besser aus. Mit dem Attribut width='??%' kann man zudem festlegen, über wieviel Prozent der Seite sich die Tabelle erstrecken soll.

{| width="100%"
|+
! Anzeige
! Code
|-
|
{| {{prettytable}}
!Auto
!Fahrrad
|-
|Boot
|Bahn
|-
|Taxi
|Flugzeug
|}
|<pre> 
{| {{prettytable}}
!Auto
!Fahrrad
|-
|Boot
|Bahn
|-
|Taxi
|Flugzeug 
|}
</pre>
|}


== Code ==
C-Code und Assembler-Code wird in <nowiki><c></nowiki>- bzw. <nowiki><asm></nowiki>-Tags gesetzt, um bunten Code zu erhalten. Eine Liste aller verfügbaren Sprachen befindet sich bei den [[Spezial:Version#Installierte_Erweiterungen|Versionsinformationen]]. In der folgenden Tabelle sind für ein paar Sprachen Beispiele, die die Verwendung illustrieren sollen, aufgelistet.

{| {{prettytable}}
! width="10%" |Sprache
! width="45%" |Beispiel
! width="45%" |Darstellung
|-
|C
|
 <nowiki><c>#include <stdio.h></nowiki>
 
 <nowiki>int main() {</nowiki>
 <nowiki>    int i = 1;</nowiki>
 <nowiki>    return i;</nowiki>
 <nowiki>}</c></nowiki>
|
<c>#include <stdio.h> 

int main() {
   int i = 1;
   return i;
}</c>
|-
|Assembler
|
 <nowiki><asm>mov eax, cr0</nowiki>
 <nowiki>or eax, 1</nowiki>
 <nowiki>mov cr0, eax</asm></nowiki>
|
<asm>mov eax, cr0
or eax, 1
mov cr0, eax</asm>
|-
|Andere Sprachen
|
 <nowiki><code></nowiki>REM Important
 ECHO Hello Batch<nowiki></code></nowiki>
|
<code>REM Important
ECHO Hello Batch</code>
|}

Die selbe Formatierung wie mit dem <nowiki><code></nowiki>-Tag erhält man auch, wenn man ein Leerzeichen vor jede Zeile des Codes setzt.

== Diskussionsfäden ==
Auf den Diskussionsseiten wird es schnell unübersichtlich, wenn nicht jeder Nutzer selbst dafür sorgt, dass seine Beiträge eingerückt werden. Um die Diskussion einigermaßen strukturiert zu halten, werden Antworten pro Ebene mit jeweils einem weiteren Doppelpunkt eingerückt. Zum Beispiel so:
 Ich starte eine Diskussion. <nowiki>--~~~~</nowiki>
 : Also ich finde diese Diskussion verdient Antworten. <nowiki>--~~~~</nowiki>
 :: Ich bin eine Antwort. <nowiki>--~~~~</nowiki>
 ::: Ich bin eine Antwort mit mehreren Absätzen.
 ::: Dieser zweite Absatz darf im Beispiel nicht fehlen. <nowiki>--~~~~</nowiki>
 :: Ich bin auch wichtig. <nowiki>--~~~~</nowiki>
Und das Ergebnis sieht so aus:

Ich starte eine Diskussion. --Autor0 23:59, 31. Dez. 1899 (CEST) 
: Also ich finde diese Diskussion verdient Antworten. --Autor1 0:00, 1. Jan. 1900 (CEST) 
:: Ich bin eine Antwort. --Autor2 10:10, 1. Jan. 1900 (CEST) 
::: Ich bin eine Antwort mit mehreren Absätzen.
::: Dieser zweite Absatz darf im Beispiel nicht fehlen. --Autor3 13:37, 1. Jan. 1900 (CEST) 
:: Ich bin auch wichtig. --Autor4 21:42, 1. Jan. 1900 (CEST) 

Wer einen ausführlichen Text verfasst, kann diesen auch durch das Einfügen von <tt><nowiki><br></nowiki></tt> in Absätze gliedern.

'''Tip:''' Für längere Diskussionen empfiehlt es sich unser [http://forum.lowlevel.eu/ Forum] zu nutzen.

=== Signatur ===
Kommentare in Diskussionsseiten sollen immer durch ein <nowiki>--~~~~</nowiki> am Ende signiert werden. Die Wiki-Software fügt dann automatisch die/das richtige Uhrzeit/Datum sowie den Nutzernamen ein. Dies erleichtert erheblich den Überblick in Diskussionen zu behalten, wer was gesagt hat. Vor allem in längeren Diskussionen ist das sehr wichtig und da niemand im voraus weiss wie lang seine Diskussion mal werden wird soll das immer vom ersten Beitrag an konsequent durchgeführt werden.

== Wikiformatierung unterdrücken ==
Wenn man zum Beispiel Wikibefehle erklären will, oder eine Kollision mit den Befehlen von Mediawiki hat, kann man das <nowiki><nowiki></nowiki>-Tag benutzen, um zu verhindern, dass Mediawiki den enthaltenen Text formatiert.

== HTML ==
Die Verwendung von HTML ist möglichst zu vermeiden, und es sollten ausschließlich die eingebauten MediaWiki-Befehle (auch die, die hier nicht dokumentiert sind) verwendet werden. Man kann auch in der [http://meta.wikimedia.org/wiki/Help:Editing MediaWiki-Dokumentation] nach Alternativen suchen, oder im [[IRC]] nachfragen.
